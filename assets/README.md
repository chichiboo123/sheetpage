# 홍보용 자산

앱 번들에는 포함되지 않습니다. `public/og-image.png`만 사이트와 함께 배포됩니다.

| 파일 | 용도 |
| --- | --- |
| `cardnews/cards.html` | 카드뉴스 5장의 원본. 문구·색을 고쳐 다시 뽑을 수 있습니다. |
| `cardnews/sheetpage-0*.png` | 1920×1920 카드뉴스 (표지 · 문제인식 · 개요 · 기능 · 아웃트로) |
| `og-image.html` | 링크 공유 미리보기(1200×630) 원본 → `public/og-image.png` |

## 다시 렌더링하기

Pretendard가 설치된 환경에서 각 아트보드를 지정 크기로 스크린샷하면 됩니다.
`.card`는 1920×1920, `.og`는 1200×630으로 고정되어 있습니다.
